# Japanese Bot — Android App
## FX + OTC Binary Signal Tool with Screen Reader

---

## BUILD KARNE KA TARIKA (Android Studio)

### Step 1 — Android Studio Install karein
https://developer.android.com/studio download karein

### Step 2 — Project Open karein
File → Open → JapaneseBot folder select karein

### Step 3 — Build karein
Build → Build Bundle(s) / APK(s) → Build APK(s)

APK mil jaegi:
app/build/outputs/apk/debug/app-debug.apk

### Step 4 — Phone mein Install karein
1. Phone mein "Unknown Sources" enable karein
   Settings → Security → Unknown Sources → ON

2. APK file phone mein transfer karein (USB ya WhatsApp)

3. APK tap karke install karein

---

## APP KAISE USE KAREIN

### Pehli Baar Setup:
1. App open karein
2. "Enable Accessibility Service" button dabayein
3. Settings mein "Japanese Bot Scanner" enable karein
4. Wapas app mein aayein — green status dikhega

### Signal Lene Ka Tarika:
1. Quotex app open karein
2. Jo currency pair trade karna ho woh select karein
3. Notification bar mein "SCAN" button dabayein
4. 2-3 second mein notification mein signal aayega:
   - ↑ UP — BUY karein
   - ↓ DOWN — SELL karein
   - Match Score bhi dikhega

### Auto Scan:
- App mein "Auto Scan" toggle ON karein
- Har 30 second mein automatically signal aayega

## FEATURES
- Quotex screen read karke pair detect karta hai
- AlphaVantage se live FX data
- OTC pairs bhi support karta hai
- 6 indicators: RSI, MACD, MA Cross, Momentum, Stochastic, Candle Pattern
- Notification mein SCAN button
- Auto scan mode
